# 📖 Leitura PDF – PWA
# 📌 Sobre o projeto

O Leitura PDF é um Progressive Web App (PWA) desenvolvido para facilitar a leitura de documentos PDF diretamente no navegador. Além da visualização das páginas, o aplicativo utiliza a API SpeechSynthesis para realizar a leitura em voz alta do conteúdo, oferecendo uma experiência mais acessível para estudos e leitura de documentos.

O projeto foi pensado para funcionar tanto em computadores quanto em dispositivos móveis, podendo ser instalado como um aplicativo através das funcionalidades de PWA.

# ✨ Funcionalidades
Abertura de arquivos PDF diretamente pelo navegador.
Visualização da página atual.
Leitura em voz alta utilizando SpeechSynthesis.
Controle de velocidade da leitura.
Seleção de diferentes vozes disponíveis no dispositivo.
Navegação por páginas.
Continuação automática da leitura entre páginas.
Salvamento automático da última página lida.
Armazenamento das preferências do usuário (voz e velocidade).
Interface otimizada para dispositivos móveis.
Instalação como Progressive Web App (PWA).

# 📱 Interface

A interface foi desenvolvida com foco na simplicidade e facilidade de uso.

Ela permite:

abrir documentos PDF;
visualizar a página atual;
iniciar ou pausar a leitura;
alterar a velocidade da voz;
selecionar diferentes vozes;
continuar a leitura automaticamente até o final do documento.

# ⚙ Como utilizar
Abra o aplicativo no navegador.
Selecione um arquivo PDF.
Escolha a voz desejada.
Ajuste a velocidade da leitura.
Clique em Começar Leitura.
O aplicativo continuará lendo automaticamente as páginas do documento.
